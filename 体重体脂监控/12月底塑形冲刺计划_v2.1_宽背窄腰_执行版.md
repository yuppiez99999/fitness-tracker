# 12月底塑形冲刺计划 v2.1 — 宽背窄腰执行版

> **制定日期**: 2026-08-04（基于身高175cm / 体重67.45kg / 体脂16.9% 实测）
> **目标日期**: 2026-12-28（22周）
> **核心目标**: 体脂降至 **12.5–13.5%** + 背阔肌 V 字宽度 + 腰围 -4~6cm + 胸肌清晰饱满 + 腹肌 6 块显现
> **基于 v2.0 优化**: 针对 37 岁、骨骼肌率偏低（44.3%）基础，重新校准热量缺口、下调训练容量、延后有氧、精简补剂

## 二、v2.1 相比 v2.0 的关键优化

| 维度 | v2.0 | v2.1 优化 | 原因 |
|:-----|:-----|:----------|:-----|
| 热量缺口 | 标称 150 kcal（实际约 500–800） | **训练日 2300 / 休息日 2100** | TDEE 被低估，原缺口过大会掉肌肉 |
| 背周总量 | 34 组 | **22–26 组**（周一 12 + 周四 10–12） | 肌肉量低，容量过大反致神经疲劳 |
| 俯身杠铃划船 | 周四主项 | 改为 **T 杠划船 / 胸支撑划船** | 37 岁下背累积压力风险 |
| 阿诺德推举 | 肩日主项 | 改为 **坐姿哑铃肩推** | 肩袖压力小，收益相当 |
| 空腹有氧 | Phase 2 启动 | **Phase 1 完全不做**，Phase 2 最多 2 次 | 避免皮质醇过高、肌肉分解 |
| 补剂 | 堆叠 9 种 | **精简至 5 必需 + 3 建议** | CLA 证据弱；电解质饮料与控盐冲突 |
| 真空腹 | 直接 60 秒 ×5 | **30→45→60 秒递进** | 防头晕，保证可持续 |

### Phase 3（W15–W22）线条冲刺（碳水循环）
| | 高碳日(背/腿) | 中碳日(背/泵感) | 低碳日(胸/肩) | 休息日 |

**执行要点**:
- 控盐 <4g/天，周日控盐日 <3g；加工肉/酱料全避免

- 高碳日碳水从食物获取优先；电解质饮料仅大量出汗时用，注意钠含量

## 六、Phase 2 / Phase 3 概要

**Phase 2（W7–W14）**:
- 复合动作每 2 周 +2.5% 重量
- 真空腹每日 2 次（晨 + 练后），60 秒 ×5 组
- 晨间空腹 LISS 最多 2 次/周，20 分钟，心率 <125 bpm
- 减载周：W8、W13（-40%）

**Phase 3（W15–W22）**:
- 启用碳水循环（见第三节）
- HIIT 最多 2 次/周，不与腿日重叠
- 减载：W17（-40%）、W21（-50%）
- 峰值周 W22：量降至 50%，高碳日 280g 碳水 + 低钠 + 充足睡眠

## 八、监控与调整触发

| 情况 | 触发 | 调整 |
|:-----|:-----|:-----|
| 减重过快 | 连续 2 周 >0.5kg/周 | 训练日 +100–150 kcal |
| 体重不降 | 连续 2 周不变 | 休息日 -100 kcal + 有氧 +1 |
| 力量下降 | 连续 2 次训练退步 >5% | 加热量、查睡眠蛋白 |
| 体脂不降 | 连续 3 周不变 | 加有氧 + 查钠摄入 |
| 腰围不缩 | 连续 3 周不变 | 控盐更严 + 髂腰肌拉伸 |
| 疲劳累积 | 静息心率 +5 bpm | 立即减载 3 天，-50% 容量 |

**核心理念**: 背阔肌宽度 = 每周 2 次背 + 引体为核心；窄腰 = 真空腹每日 + 控盐 + 体脂 ≤13%；清晰腹肌 = 体脂 ≤13% + 极高蛋白；22 周 = 阶段化 + 减载 + 碳水循环 + 峰值周。
